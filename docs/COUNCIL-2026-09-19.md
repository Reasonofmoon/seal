## Sealed (감독관 · room wrap)

**Invariant:** every `code` gate runs as a **harness step** (never a pane prompt). Keys only via env / box-secrets. FAIL · 「확인 실패」 · API failure → **escalate**. Auto-click approval UI · unapproved READY / merge / publish / redeploy = **0**.

Evidence SSOT: `runs/<id>/*-done.md` (+ artifacts). Harness success = file exists + schema pass only — no `agent read` scrollback.

| **Frontier Gap** | `human_form_required`; Strike success ≠ Seal adopt; `PRIMARY_SOURCE_NOT_FOUND` = `code` fail | form-not-submitted metric_pass / adopt without decision / 2nd-hand-only qualify **0** |

### Shared harness rules (all)

1. Pane never calls TypeSafe / claim-gate / github-qa-score / env checks — **harness step only**.
2. On FAIL or unverifiable → stamp escalate; put READY / merge / publish / redeploy / adopt on **queue only**.
3. Silent when nothing to report; if cannot verify, say 「확인 실패」 — never invent pass.
